# 桌面伴伴 · Desktop Companion

<img src="docs/mochi.png" width="160" alt="原创桌面伙伴小团">

简体中文 · [English](README.md)

一个使用 Swift 和 AppKit 制作的轻量 macOS 桌宠。自带原创角色「小团」，提供直观的电脑状态和 Apple 蓝牙配件电量小窗。不装模型也能使用桌宠及监控功能，无需账号或 Python。

## 功能

- **原创小团**：由程序绘制，可调整大小、拖动位置。
- 可缩放窗口显示 CPU/GPU 占用、可读取的温度、内存压力和存储余量。
- 读取 macOS 提供的 Apple 耳机、鼠标、键盘、触控板电量记录。
- 可选整点气泡报时，随时隐藏、暂停或完全退出。
- 设置里切换中文和英文界面。
- 实验性散步默认关闭；开启时隐藏脚边输入框并启用鼠标穿透，关闭后恢复原设置。
- 可选安装本地 Qwen3-1.7B 文字聊天。模型和运行环境不随基础应用打包。小团知道现在的时间，「8 点半要到、路上 40 分钟，几点出门」这类计算由程序算准；会记住你在聊天里说的关于自己的事（只存在本机，可修改或清空）；不扮演恋人；说到很难熬的话题时，回复后附上按系统地区给出的求助热线。
- 可选语音：点一下开始录音、再点一下停止，转写后检查文字再发送；本机识别，跟随界面语言，没有唤醒词常驻监听。回复可以用系统声音朗读，也可以另外安装**小团自己的声音**（本机神经网络朗读），整点报时也能念出来。

## 系统要求

| 功能 | 要求 |
|---|---|
| 桌宠和状态小窗 | Apple Silicon Mac，macOS 14 或更新版本 |
| 可选本地文字模型 | Apple Silicon，macOS 26 或更新版本，可选安装时至少 3 GiB 可用空间 |
| 语音输入 | 麦克风权限。macOS 26 及以上用系统本机识别（第一次可能下载一次语言模型）；macOS 14–15 还需要语音识别权限并打开「听写」 |
| 可选朗读声音 | Apple Silicon，macOS 14 或更新版本，约 2.5 GB 下载，安装时至少 4 GiB 可用空间 |
| 从源码构建 | Xcode 命令行工具和兼容的 macOS SDK |

没有 Intel 发行包。不同机型、系统和配件可读取的数据不同；不可读取时显示不可用，不编造估算值。

## 安装和使用

1. 从 [Releases](https://github.com/Bf190t/mac-desktop-companion/releases) 下载 Apple Silicon ZIP。
2. 解压，将 **Desktop Companion.app** 拖到「应用程序」。
3. 启动后，通过菜单栏 **✿** 入口打开设置、电脑状态或蓝牙电量窗口。
4. 在「设置 → 语言」中选择简体中文或 English。

首发采用本地临时签名，**没有 Apple Developer ID 签名和 Apple 公证**，下载后首次打开可能出现系统安全提示。请先核对源码、来源和发行页的校验值，再决定是否信任。Apple 官方的[安全打开 Mac App 说明](https://support.apple.com/zh-cn/102445)介绍了针对单个应用的「仍要打开」流程；也可以自行从源码构建。本项目不要求关闭 Gatekeeper 或降低系统整体安全设置。

需要停止时，在菜单栏选择「完全退出」。应用不会安装开机启动项或后台服务。

## 从源码构建

安装 Apple 命令行工具后运行：

```sh
git clone https://github.com/Bf190t/mac-desktop-companion.git
cd mac-desktop-companion
./scripts/build.sh
./scripts/test.sh
```

产物为 `dist/Desktop Companion.app`。默认不下载或打包模型、Python 运行时和用户数据。更多检查范围见[开发与验证说明](docs/DEVELOPMENT.md)。

## 可选本地聊天

打开「本地模型 · 状态与调试」窗口，点击「安装可选聊天模型…」后才下载模型。下载需要联网，正常推理在本机进行，模型子进程禁止联网。

- 模型为 [Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B)，使用固定版本的 [MLX 社区 4-bit 转换](https://huggingface.co/mlx-community/Qwen3-1.7B-4bit/tree/3b1b1768f8f8cf8351c712464f906e86c2b8269e)。
- 模型文件合计约 **984 MB**，本次完整安装实测约 **1.42 GiB**（含 Python 和依赖），安装过程中至少需 **3 GiB** 可用空间。
- 按内置版本和哈希清单下载、校验，存放在应用自己的 Application Support 目录中，不修改应用包。
- 通常在 **120 秒**没有活动后卸载模型；可选延长为 30 分钟。锁定、睡眠、退出和内存压力较高时可能提前卸载。
- 对话只保存在内存中。聊天模型没有电脑操作能力，也不接收电脑指标、蓝牙记录、屏幕或文件。
- 小模型可能误解、编造信息或遗漏长对话细节。提示词和过滤规则不能保证回答正确。

本地数据、权限和实验语音行为见[隐私说明](docs/PRIVACY.md)。

## 可选朗读声音

回复和整点报时可以用小团自己的声音来念。在「本地聊天 · 模型与语音」里点「安装朗读声音…」；没装好之前，或者朗读声音暂时不可用时，改用系统声音念。

- 模型：[Qwen3-TTS 0.6B Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，使用固定版本的 [MLX 社区 8bit 转换](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-Base-8bit/tree/50f45ef0047cde7e84c2ef04326acb8ada2436a7)，Apache 2.0。约 2 GB 模型文件，加上固定版本的 Python 运行时和锁定哈希的依赖包，存放在本应用自己的 Application Support 目录。
- 小团的声音是用 Qwen3-TTS 声音设计模型按一段文字描述造出来的，朗读时只按音色克隆这段合成样本 [voice/companion_voice.wav](voice/companion_voice.wav)，不是任何真人的录音。
- 边生成边念：在 M4 MacBook Air 上第一声约 0.2–0.4 秒，比实时快约 2 倍。安装时一次录好中英文各 24 段整点报时，报时不用加载模型。
- 朗读进程禁止联网；开始打字或录音时加载，闲置 5 分钟或内存紧张时释放。在出声之前出错的话，这一句改用系统声音念。

## 如何理解读数

电脑状态窗口可见时才采样 CPU/GPU 和温度，节能条件下会降低频率。存储每小时刷新，支持手动刷新。内存压力统计最近一小时中实际观察到的时段；睡眠和暂停期间不会补成绿色记录。

蓝牙电量来自 **macOS 最近可用的记录**，并非持续实时读取。耳机盒关闭或设备断开时可能显示较旧的读数或没有数据。温度、GPU 以及部分配件记录使用非公开的只读接口，系统升级可能改变其行为。应用不控制风扇，也不安装高权限辅助程序。
