# Crisis support lines / 求助热线

When a chat message suggests the user may be in crisis (for example "I don't want to live anymore" or 「不想活了」), the reply ends with one short line for the region set in macOS (System Settings › General › Language & Region). Nothing is sent anywhere. The table lives in `app/Sources/ChatBoundary.swift`.

Every number below was checked on the service's own website or a government page on **2026-11-12**. Hours and numbers change; if one is wrong, please open an issue with the official source.
